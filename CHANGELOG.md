# Rocket Radar 0.3.0

- Now also for WoW Forever: the same addon loads there with its own spell lists (interrupts, defensives, crowd control and dispels taken from Forever's game data, every spell rank included). Alerts in Forever play the sound for every harmful effect of the chosen type.
- Alerts tab: the sound list is wider, so every sound name shows in full, in every language.
- Alerts tab: "Alerts: all" now reads "Choose" instead of showing empty.
